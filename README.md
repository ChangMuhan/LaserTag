# 激光打靶（靶子端）代码 — TM4C123G

## 一、文件夹结构

```
laser_target_tm4c123g/
├── main.c            主程序：初始化各模块 + 计分逻辑
├── photoresistor.h   光敏电阻模块接口
├── photoresistor.c   光敏电阻：ADC 读取 + 环境光基线 + 突增命中判断
├── st7735.h          显示屏模块接口
├── st7735.c          显示屏：ST7735 SPI 驱动 + 数字显示
├── uart.h            串口模块接口
├── uart.c            串口：UART0 调试打印
└── README.md         本说明
```

各模块职责：
- **photoresistor**：只负责「读光、判断有没有被打中」，不关心分数和显示。
- **st7735**：只负责「在屏上画颜色、画数字」。
- **uart**：只负责「往串口打印」。
- **main**：把所有模块串起来，做计分和游戏逻辑。

## 二、接线表（TM4C123G LaunchPad）

**光敏电阻模块（AO 方案）：**

| 模块引脚 | 接 TM4C123G |
|---|---|
| VCC | 3.3V |
| GND | GND |
| AO | **PB4**（ADC0 AIN10） |
| DO | 不接 |

**ST7735 显示屏：**

| 屏引脚 | 接 TM4C123G |
|---|---|
| SCK | **PA2**（SSI0Clk） |
| SDA/MOSI | **PA5**（SSI0Tx） |
| CS | **PB1** |
| DC | **PB2** |
| RST | **PB3** |
| BL | 3.3V |
| VCC | 3.3V |
| GND | GND |

> ⚠️ TM4C123G 是 3.3V 器件，GPIO 不 5V 耐受。所有模块都用 3.3V 供电。

## 三、如何在 CCS 里使用

1. 新建（或复制你 lab 的）一个 TivaWare 工程，确认已链接 `driverlib`（TivaWare）。
2. 把本文件夹里的 `main.c`、`photoresistor.c`、`st7735.c`、`uart.c` 加入工程，`.h` 也一起加入（或放到 include 路径）。
3. 确认 TivaWare 的 include 路径正确（能 include 到 `inc/` 和 `driverlib/`）。
4. 编译 → 烧录到 LaunchPad。
5. 打开串口终端（PuTTY / Tera Term / CCS Terminal），选板子 COM 口，**115200 波特率**。

## 四、上电效果

1. 终端打印：`Ready. Baseline=xxxx`（xxxx 是环境光基线，0~4095）。
2. 手机闪光灯/激光**直射**光敏电阻：
   - 屏幕闪红一下，然后显示新分数（如 `1`、`2`…）。
   - 终端打印 `HIT 1`、`HIT 2`…
   - 板载蓝灯（PF2）闪一下。
3. 灯一直照着不动 → 只加一次分（边沿触发）；移开再照 → 继续加分。

## 五、调参（重要）

- **突增阈值**：在 `photoresistor.c` 里 `hit_margin`（默认 300）。
  - 自然光下也误触发 → 调大。
  - 手机灯照了不触发 → 调小。
  - 建议：先看终端打印的 `Baseline=`，再用灯照时看读数涨到多少，把阈值设成「灯光读数 − 基线」的一半左右。
- 给光敏**套遮光罩**（深色管子），能让基线和灯光读数差距拉大，阈值好调很多。

## 六、已知注意事项

- **ST7735 屏颜色反了**：把 `st7735.c` 初始化里的 `write_cmd(0x20); // INVOFF` 改成 `write_cmd(0x21); // INVON`。
- **屏幕方向/颜色不对**：不同厂家 ST7735 色序版本不同，可调整 `0x36`（MADCTL）的值（当前 `0xC8`）。
- **只支持数字显示**：`st7735.c` 目前只带了 0~9 的字体，够显示分数；要显示文字（如 "HIT"）再扩展 `font_digits` 和 `ST7735_DrawChar`。
- **激光是脉冲**：手机灯是持续光，边沿触发没问题；后续换激光（几十毫秒脉冲）时，需要把采样做快、或改用中断，这一步后面再改。
